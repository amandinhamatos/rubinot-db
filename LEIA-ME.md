# RubinOT Database

1. Instale o Python (python.org) e, na pasta deste site, rode: `python coletar_itens.py`
   Isso cria `data/items.js` e as imagens em `img/items/`. Se ficar pela metade, rode de novo.
2. Abra o `index.html` com duplo clique para testar (funciona offline).
3. Para publicar no GitHub Pages: crie o repositório (github.com/new, público), instale o GitHub Desktop,
   "Add local repository" apontando para esta pasta, faça "Commit" e "Publish repository".
   No repositório: Settings > Pages > Branch `main` / pasta `/ (root)` > Save.
   O link fica em https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/
4. Seus dados (personagens, preços, metas) ficam só no navegador, nunca no repositório.
   Para levar de um aparelho ou endereço para outro: Exportar backup e Importar backup.
